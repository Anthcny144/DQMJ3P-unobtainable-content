# DQMJ3P - Unobtainable content
This 3GX plugin allows unlocking content locked behind discontinued features including [online play and SpotPass](https://en-americas-support.nintendo.com/app/answers/detail/a_id/63227/~/announcement-of-discontinuation-of-online-services-for-nintendo-3ds-and-wii-u) as well as hard-to-reach ones like StreetPass and monster transfer.<br>
The main goal is to make DQMJ3 and DQMJ3P 100% completable to this day even though some of the content has become unobtainable.

# Compatibility
This plugin is compatible with **every DQMJ3 and DQMJ3P versions**, including all known translations ([english](https://github.com/Akoi89/DQMJ3P-english-fixed/), [french](https://dragonquest-fan.com/forum/index.php?subjectID=14712), [italian](https://github.com/Lurpigi/DQMJ3P-IT-FanTranslation) and [spanish](https://www.brockprojects.net/dragon-quest/dragon-quest-monsters-joker-3-professional)).<br>
<sub><sub style="color: #A0A0A0;">The plugin should be compatible with every untranslated and translated version as long as the game's code length is unchanged.</sub></sub><br>

The plugin works on 3DS, [Azahar](https://azahar-emu.org/) and [AzaharPlus](https://github.com/AzaharPlus/AzaharPlus/). Other emulators are obsolete and may not support 3GX plugins.

# Installing on 3DS
- Insert your SD card into your computer
- Download the zip archive from the [latest release](https://github.com/Anthcny144/DQMJ3P-unobtainable-monsters/releases/latest)
- <b>Extract</b> the content of the zip file. You should have a single `luma` folder
- Put this `luma` folder at the root of your SD card (replace files if asked to)
> [!WARNING]
> Do <b>NOT</b> put the zip file! You need to put the `luma` folder extracted from the zip file.<br>
- Eject your SD card and plug it back in your 3DS
- Turn on your 3DS and press `L + Down + Select` on the Home Menu
- Toggle on "Plugin Loader"
- Start the game. On the title screen, press Select to open the menu<br>

# Installing on emulator (computer)
> [!NOTE]
> Make sure to use [Azahar](https://azahar-emu.org/) or [AzaharPlus](https://github.com/AzaharPlus/AzaharPlus/).<br>
> Other emulators are obsolete and may not support 3GX plugins.<br>
- Launch Azahar
- On the top left corner, press "File", hover "Open Azahar Folder" and click "SDMC Folder"
> [!NOTE]
> If you only see the "Open Azahar Files" option, that means you have an older Azahar version. In this case, open this folder and create the `sdmc` folder yourself in the opened folder.
- Download the zip archive from the [latest release](https://github.com/Anthcny144/DQMJ3P-unobtainable-monsters/releases/latest)
- <b>Extract</b> the content of the zip file. You should have a single `luma` folder
- Put this `luma` folder in the `sdmc` folder you opened (replace files if asked to)
> [!WARNING]
> Do <b>NOT</b> put the zip file! You need to put the `luma` folder extracted from the zip file.<br>
- On Azahar, on the top left corner, click on "Emulation", then "Configure"
- Go to "System", scroll down and tick "Enable 3GX plugin loader", then click "OK"
- Start the game. On the title screen, press Select to open the menu<br>

# Installing on Android
<sub><sub style="color: #A0A0A0;">I could not test the plugin on Android by myself so these steps may be a little vague.</sub></sub><br>
- Download the zip archive from the [latest release](https://github.com/Anthcny144/DQMJ3P-unobtainable-monsters/releases/latest)
- <b>Extract</b> the content of the zip file. You should have a single `luma` folder
- Copy the extracted `luma` folder
- Navigate into your Azahar install folder
- Paste the `luma` folder in the `sdmc` folder (create it if it does not exist)
- There may be a "Enable 3GX plugin loader" option to enable, I'm not sure
- Start the game. On the title screen, press Select to open the menu<br>

# Install FAQ
<details>
    <summary>I launched the game, but nothing happens!</summary>
    A blue screen should flash when the game boots. If it doesn't, something went wrong during installation. Make sure you extracted the contents of the downloaded zip file, placed them at the root of your SD card / sdmc folder, and enabled the Plugin Loader option.
</details><br>
<details>
    <summary>A different plugin is loading!</summary>
    Try switching the rendering engine from OpenGL to Vulkan, or vice versa:<br>Emulation -> Configure... -> Graphics -> Advanced -> Graphics API
</details><br>
<details>
    <summary>A different plugin is loading!</summary>
    If another plugin is being loaded, make sure you don't have multiple 3gx files in both /luma/plugins/00040000001ACB00/ and /luma/plugins/000400000016AD00/.
</details><br>
<details>
    <summary>The font of the menu looks trash!</summary>
    Use <a href="https://github.com/azahar-emu/ArticBaseServer">Artic Base</a> to import your 3DS' system files, including the font. This will also fix the "ん" character not being rendered by the default system font on emulator.
</details><br>
